for BC

Category	Test Procedure	Acceptance Criteria

1 BC-to-RT, RT-to-BC, RT-to-RT & Broadcast Commands
Configure a BC frame with BC-to-RT (16 words), RT-to-BC (16 words), RT-to-RT (8 words), and Broadcast (RT 31, 4 words); verify on MT and scope.	
Exchanges valid Command/Data/Status words with 4.0–12.0 µs RT turnaround; Broadcast sets Status Bit 15 internally with zero Status Words on the bus.

2 Message Scheduling & Frame Execution
Run an 80 ms Major Frame (10 ms Minor Frames) mixing 10 ms, 20 ms, and 80 ms rates, plus inject an asynchronous message mid-run.
Executes messages at exact harmonic rates with $\le \pm 5\ \mu\text{s}$ minor-frame jitter; async message inserts cleanly without shifting subsequent frame boundaries.

3 Real-Time Message Data Update (Excel / User Input)
Modify payload words manually via GUI/API and stream a time-indexed Excel/CSV profile during active 50–100 Hz BC-to-RT transmission.	
Updates appear on the wire in the next scheduled frame without halting the BC; double-buffering prevents data tearing and executes Excel steps with zero frame drops.

4 Standard 1553B Transaction Execution
Configure a BC frame executing standard transactions (BC-to-RT, RT-to-BC, RT-to-RT, Broadcast, and Mode Codes) across active RTs and verify via passive Monitor Terminal (MT) and oscilloscope.
Executes all standard word formats (Command, Data, Status) with valid syncs, odd parity, $\ge 4.0\ \mu\text{s}$ inter-message gaps, and 4.0–12.0 µs RT turnaround (zero Status response on Broadcast).


5 Real-Time EGU Simulation (User Input & Predefined Waveforms)	
Map ICD scaling rules (Signed/Unsigned BNR, BCD, Float, discretes) to BC subaddresses, then inject manual EGU step values and run predefined dynamic waveform generators (Sine, Square, and Sawtooth) during active transmission.	
Converts EGU values and waveform steps accurately into raw 16-bit bus words in real time without halting the BC, matching decoded MT EGU plots within ICD quantization tolerance.


for MT

1 Continuous Bus Monitoring & 100% Capture
Run 100% bus-load traffic (~1,450+ msgs/sec across Bus A/B) for 4+ hours while logging to host RAM/disk.
Captures 100% of Command, Data, and Status words with zero FIFO overflows, zero DMA drops, and 100% payload checksum match.


2 Live Protocol Decoding & Display (Command, Status & Data Words)
Transmit mixed transactions (BC-RT, RT-BC, RT-RT, Broadcast, Mode Codes) and inspect the live analyzer display.	
Accurately parses and displays Command fields, Status flags, and Data words (Hex/Bin/Dec) without misidentifying Command vs. Status words.


3 Timestamped Message Capture & Timing Analysis	
Feed external IRIG-B (AM/DCLS) sync during active capture, record a multi-minute log, and run timing analysis.
Stamps every word to $\le 1\ \mu\text{s}$ IRIG-B accuracy and accurately computes RT response times (4.0–12.0 µs), IMGs, message rates, and bus load %.


4 Passive Monitoring Without Affecting Bus Comm
Connect MT to an active bus; power-cycle, reset, hot-plug/unplug the unit, and attempt forced Tx API calls.
Transmitter stays physically locked out, input impedance stays $\ge 1000\ \Omega$ (transformer) / $\ge 2000\ \Omega$ (direct), and zero bus errors occur.

5 Communication Errors Report & Identification
Inject parity, sync, Manchester, word-count, early/late response, and no-response timeout faults onto the bus.	
Captures malformed frames without losing sync on subsequent words and logs exact fault type, RT/Subaddress, and timestamp.


6 Real-Time Monitoring of Selected EGU
Load an ICD file, select EGU parameters (BNR, BCD, Float, discretes), and stream live dynamic waveforms from BC/RTs.
Converts raw 16-bit words into scaled EGU values in real time ($\ge 50\text{–}100\text{ Hz}$) with smooth watch-table/chart updates within ICD tolerance.





for RT


1 BC Command Processing
Send valid BC-RT, RT-BC, RT-RT, Broadcast, and illegal subaddress commands.	
Decodes command fields accurately; responds within 4.0–12.0 µs, stays silent on Broadcast, and sets Message Error (Bit 9) on illegal subaddresses.


2 Mode Code Processing
Send Mode Codes (Transmit Status, Synchronize, Transmit BIT, Inhibit Terminal Flag, Reset RT).	
Executes per SAE AS4111, updates terminal state, and returns Status (plus data word if applicable) within 4.0–12.0 µs.

3 Data Transmission & Reception
Execute 1–32 word Rx/Tx transfers at 100% bus load, plus inject parity and word-count errors.
Stores valid Rx words and sends Tx words MSB-first with odd parity; rejects corrupted words and suppresses Status on format errors.


4 Protocol-Compliant Status Word Generation
Trigger internal RT flags (Busy, Service Request, Subsystem, Terminal Flag, Broadcast, Message Error) and poll via BC.	
Returns 20-bit Status Word with valid sync, RT address, exact active flag bits, and odd parity within 4.0–12.0 µs.


5 Real-Time Data Update via Excel
Stream a time-indexed Excel/CSV file into an RT transmit subaddress while BC polls at 50–100 Hz.	
Updates Tx buffers dynamically without response drops; double-buffering prevents data tearing within messages.


for Communication 

1 Cycle Periods & Multi-Rate Timing
Configure fixed minor frames (1 ms–50 ms) and harmonic major frames under heavy CPU load; measure frame intervals on a bus analyzer.
Period matches target within $\le \pm 1\ \mu\text{s}$ (jitter $\le \pm 5\ \mu\text{s}$) with zero cumulative drift.

2 Scheduled Frame Execution & Control	
Run a cyclic frame table with idle dead-time padding, Status-word conditional branching (JUMP/CALL), and dynamic message SKIP toggles.	
Branches execute in real time without host delay; idle padding and message toggles preserve frame boundaries.

3 User-Configurable Message Timing
Set custom Inter-Message Gaps (4–500 µs), time-slot offsets, and no-response timeouts (14–50 µs) via API.
Wire timing matches settings within $\le \pm 1\ \mu\text{s}$ and clamps inputs below 4.0 µs gap / 14.0 µs timeout.

4 Accurate Execution of Comm Schedules	
Run a multi-rate schedule (10 ms, 20 ms, 80 ms) with an async message injection and an induced minor-frame overrun.	
Messages hit exact harmonic slots, async messages insert cleanly, and frame overruns recover without hanging.



for Dual Bus

1 Independent Operation of Both Buses
Run active traffic on Bus A while shorting/opening Bus B (and vice versa) and measure signals on both channels.
Dedicated transceivers maintain $\ge 40\ \text{dB}$ isolation; fault on one bus causes zero voltage drop, crosstalk, or bit errors on the other.


2 Message-Level Bus Selection
Schedule messages explicitly on Bus A or Bus B within a periodic frame, then dynamically toggle bus assignment mid-run.
BC transmits exclusively on the assigned bus; RT responds on that exact bus within 4.0–12.0 µs, and mid-run bus changes take effect cleanly on the next frame.

3 Monitoring & Analysis on Either/Both Buses
Capture mixed Bus A/B traffic (including a Bus A $\rightarrow$ Bus B failover) in dual-channel MT mode.
MT logs 100% of traffic on Bus A, Bus B, or both with $\le 1\ \mu\text{s}$ timestamps, tags channel origin (A/B), and reports per-bus load % and errors.



for error injection

1 BC-Initiated Comm Errors
Inject parity error, invalid sync, Manchester bit error, and wrong word count from BC.

Exact fault appears on wire; RT rejects corrupted message and suppresses Status response.


2 RT Response Errors
 Inject early response (< 4 microsec), late response (> 12 microsec), no-response timeout, and bad Status/Data parity from RT.

RT injects fault on target message; BC flags exact error and triggers auto-retry/bus-switch without data corruption.

3 Comm Fault Simulation
Simulate babbling RT (> 800 microsecond Tx), Bus A open/short, and forced RT Status flags (Busy, Terminal Flag).

Fail-safe timer cuts babbling Tx at 660–800 µs; BC switches cleanly to Bus B and branches on Status flags.


4 Error Detection & Reporting
Run mixed protocol/timing fault script across active RTs and inspect MT and diagnostic logs.

100% of faults logged with exact error type, RT/Subaddress, bus (A/B), error count, and $\le 1\ \mu\text{s}$ timestamp.
